# Бот для оценки выгодности покупки

Учебно-практический Telegram-проект на Python. Принимает фотографии и описание товара, собирает через Gemini с Google Search ориентиры рыночных предложений и формирует текстовую оценку потенциальной выгодности покупки с учётом найденных цен.

> **Статус:** разработка приостановлена. Код опубликован как пример личного проекта и не гарантирует точность рыночных цен, постоянную доступность API или готовность к эксплуатации в продакшене.

## Возможности

- Telegram-интерфейс на aiogram 3: обработка сообщений и фотографий.
- Двухэтапный AI-анализ: сбор цен, затем оценка предложения.
- Фильтрация источников и выбросов, учёт региона и типа объявления.
- SQLite: данные пользователей, лимиты запросов и состояния заказов.
- Логика платных запросов, подписок, реферальной программы и интеграции Robokassa.
- Асинхронная работа с API, обработка ошибок, режим локальной заглушки Gemini.

## Стек

Python, aiogram, google-genai, aiohttp, SQLite, python-dotenv.

## Запуск локально

1. Установите Python совместимой версии и создайте виртуальное окружение.
2. Установите зависимости: `pip install -r requirements.txt`.
3. Скопируйте `.env.example` в `.env.local` и заполните тестовые значения.
4. Для вызовов Gemini без оплаты используйте `MOCK_GEMINI=1` (для работы самого Telegram-бота по-прежнему нужен Telegram-токен).
5. Запустите `python bot.py`.

Примечание: запуск на новой системе и интеграционные тесты этой публичной копии отдельно не проверялись; оригинальный проект работал с внешними API и платёжным провайдером.

## Архитектура

- `bot.py` — обработчики Telegram и логика оценки;
- `db.py` — SQLite, лимиты, пользователи и заказы;
- `robokassa.py` — формирование платежей и запрос статуса;
- `config.py` — выбор окружения и конфигурация;
- `mock_gemini.py` — заглушка для разработки;
- `check_robokassa.py` — диагностический скрипт интеграции платежей;
- `system_prompt.txt` — системные инструкции для анализа.

## Безопасность

В репозитории намеренно отсутствуют `.env`, `.env.local`, базы SQLite, их бэкапы, виртуальное окружение и локальные файлы разработки. **Никогда не коммитьте рабочие ключи, пароли или реальные данные пользователей.** При необходимости замените ранее использовавшиеся ключи в кабинетах провайдеров.

## Ограничения

Результат бота зависит от качества данных и доступности поисковых источников и не является подтверждённой рыночной оценкой. Платёжные функции перед публичным запуском требуют отдельной проверки.
